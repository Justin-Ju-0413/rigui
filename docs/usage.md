# 日规 rigui 使用说明

日规（rigui）是一个移动端优先的 AI 日程计划 PWA，所有数据仅保存在浏览器本地（IndexedDB），不上传任何服务器。

## 一、设置 LLM 配置

首次使用前，打开「设置」页：

1. **API 地址**：填写 OpenAI 兼容端点的完整地址，例如 `https://api.deepseek.com/v1`（DeepSeek）、`https://api.openai.com/v1`（OpenAI），或本地服务如 `http://localhost:8080/v1`（vLLM / LM Studio）。
2. **API Key**：粘贴你的密钥。密钥只存本地。
3. **模型**：填写模型名，例如 `deepseek-chat`、`gpt-4o-mini`。
4. 点击「测试连接」确认配置可用。

> 未配置或连接失败时，AI 输入会提示错误，不影响手动创建日程。

## 二、创建事件

- **手动创建**：点击任意视图的「新建」按钮，填写标题、开始/结束时间、可选地点、重复规则（每日/每周/每月）与提醒，保存即可。
- **冲突提示**：新建或编辑的事件与已有事件重叠时，界面会展示冲突，请确认是否仍要保存。

## 三、AI 输入

在 AI 输入框直接说一句话，例如：

> 下周二下午 3 点和老王在会议室 A 开会

日规会解析出时间、地点、重复与提醒，并弹出**预览卡片**：

- 预览卡片字段可修改，确认后入库；取消则什么都不保存。
- 系统会自动把「当前时间 / 时区 / 近期日程」注入提示词，方便表达「明天」「下周五」等相对时间。

## 四、视图与提醒

- 月 / 周 / 日 / 列表四种视图，导航方式：
  - **桌面端**：左侧边栏（日程 / 目标 / 列表 / 设置）。
  - **移动端**：底部导航栏（日程 / 目标 / 列表 / 设置）。
  - **月 → 日**：点击月视图中的日期格子。
  - **日 → 周**：日视图右上角「周」按钮。
  - **周 → 月**：周视图右上角「月」按钮。
- 事件可勾选完成、编辑、删除。
- 提醒通过 Web 通知弹出：前台页面打开时约 30 秒内触发；关闭页面后由 Service Worker 处理通知点击。

## 五、目标与自动排期

- **新建目标**：打开「目标」页，填写名称、每周次数、单次时长（可选截止日期），保存后出现在目标列表。
- **排期一周**：点击目标卡片的「排期一周」，系统自动在**未来一周的工作日空闲时段**（08:00–22:00）安排任务，生成预览可「全部确认」或「放弃」；已排时段不会重复生成。
- **任务即事件**：排期任务以普通事件（`目标名 · 第 N 次`）出现在日历中，可编辑、勾选完成、删除。
- **级联删除**：删除目标时会提示同时删除其关联任务。

## 六、AI 周报

月视图顶部有「本周简报」卡片（可用 ‹ › 切换前后周）：

- **本地统计**（无需联网）：本周事件数、完成率、目标进度、每日时长分布、工作日空闲时长、冲突提醒。
- **AI 分析**：点击「AI 分析」按钮，LLM 基于统计结果生成自然语言周报（概览 / 目标 / 时间与空闲 / 下周建议）。未配置 LLM 或调用失败时，统计摘要仍可用。

## 七、导出与备份

- **ICS 导出**：可导入 Apple 日历 / Google 日历（重复事件与提醒会一并展开）。
- **JSON 备份**：支持导出全部数据、导入恢复，用于换设备或防丢失。

## 八、安装 PWA

在支持 PWA 的浏览器（Chrome / Safari / Edge）中，将日规「添加到主屏幕」，即可像原生 App 一样启动；安装后系统通知仍可用。

> 说明：当前版本支持安装与通知，但**离线缓存暂不支持**——离线时页面无法加载，数据仍保存在本地浏览器中，联网后恢复。

## 开发

```bash
npm install
npm run dev         # 本地开发
npm test            # 单元测试
npm run test:e2e    # E2E（mock LLM，不依赖真实 API）
npm run lint && npm run build
```
