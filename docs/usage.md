# 日规 rigui 使用说明

日规（rigui）是一个移动端优先的 AI 日程计划 PWA，所有数据仅保存在浏览器本地（IndexedDB），不上传任何服务器。

## 一、设置 LLM 配置

首次使用前，打开「设置」页：

1. **API 地址**：填写 OpenAI 兼容端点的完整地址，例如 `https://api.deepseek.com/v1`（DeepSeek）、`https://api.openai.com/v1`（OpenAI），或本地服务如 `http://localhost:8080/v1`（vLLM / LM Studio）。
2. **API Key**：粘贴你的密钥。密钥只存本地。
3. **模型**：填写模型名，例如 `deepseek-chat`、`gpt-4o-mini`。
4. 点击「测试连接」确认配置可用。

> 未配置或连接失败时，AI 输入会提示错误，不影响手动创建日程。

## 二、创建事件

- **手动创建**：点击任意视图的「新建」按钮，填写标题、开始/结束时间、可选地点、重复规则（每日/每周/每月）与提醒，保存即可。
- **冲突提示**：新建或编辑的事件与已有事件重叠时，界面会展示冲突，请确认是否仍要保存。

## 三、AI 输入

在 AI 输入框直接说一句话，例如：

> 下周二下午 3 点和老王在会议室 A 开会

日规会解析出时间、地点、重复与提醒，并弹出**预览卡片**：

- 预览卡片字段可修改，确认后入库；取消则什么都不保存。
- 系统会自动把「当前时间 / 时区 / 近期日程」注入提示词，方便表达「明天」「下周五」等相对时间。

## 四、视图与提醒

- 月 / 周 / 日 / 列表四种视图，右上角切换。
- 事件可勾选完成、编辑、删除。
- 提醒通过 Web 通知弹出：前台约 30 秒内触发；关闭页面后由 Service Worker 兜底。

## 五、导出与备份

- **ICS 导出**：可导入 Apple 日历 / Google 日历（重复事件与提醒会一并展开）。
- **JSON 备份**：支持导出全部数据、导入恢复，用于换设备或防丢失。

## 六、安装 PWA

在支持 PWA 的浏览器（Chrome / Safari / Edge）中，将日规「添加到主屏幕」，即可像原生 App 一样离线使用。

## 开发

```bash
npm install
npm run dev         # 本地开发
npm test            # 单元测试
npm run test:e2e    # E2E（mock LLM，不依赖真实 API）
npm run lint && npm run build
```
